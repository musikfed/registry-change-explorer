# Contributing

Thanks for taking an interest in Registry Change Explorer.

The project is currently an early read-only prototype. Useful contributions include:

- Windows Registry edge-case testing;
- SQLite/FTS performance work;
- snapshot and diff data-model design;
- accessibility and keyboard navigation;
- EN/RU wording improvements;
- privacy and safe-reporting design;
- reproducible bug reports using demo or sanitized data.

Please do **not** attach a real `registry.db` or raw Registry export to an issue unless you have reviewed and sanitized it first.

Before implementing write/delete functionality, open a design discussion first. The default project direction is inspection and explainability before mutation.
