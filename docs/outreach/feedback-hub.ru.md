# Предложение для Feedback Hub — русский черновик

## Заголовок

Registry Change Explorer для администраторов Windows — снимки, поиск и сравнение изменений Registry

## Предложение

В Windows есть хорошие инструменты для просмотра и редактирования известного участка Registry, но гораздо сложнее быстро понять, что именно изменилось после установки программы, обновления драйвера, применения политики или изменения системной конфигурации.

Я хотел бы предложить административный workflow **Registry Change Explorer**.

Основной сценарий:

1. Создать Снимок A Registry.
2. Выполнить контролируемую установку или изменение конфигурации.
3. Создать Снимок B.
4. Показать понятный diff добавленных, удалённых и изменённых ключей/значений.
5. Показать данные значений «до / после».
6. Фильтровать по hive, path, типу значения и типу изменения.
7. Экспортировать изменения как диагностический отчёт.
8. Оставить read-only режимом по умолчанию.

Я сделал независимый proof of concept, который уже демонстрирует индексированную навигацию и поиск по Registry, безопасные синтетические demo-данные и двуязычный EN/RU интерфейс.

Прототип и скриншоты: https://github.com/musikfed/registry-change-explorer

Цель идеи — не принимать за пользователя автоматические разрушительные решения, а дать администраторам прозрачный способ понять изменения Registry.
