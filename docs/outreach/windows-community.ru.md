# Пост для Windows-сообщества — русский

## Заголовок

**Сделал read-only прототип Registry Explorer. Нужен ли админам Windows нормальный Snapshot A/B diff?**

## Пост

Экспериментирую с Windows admin/developer tool под названием **Registry Change Explorer**.

Текущий прототип намеренно read-only: он индексирует ключи и значения Registry в локальный SQLite, после чего даёт быструю навигацию и поиск в двухпанельном интерфейсе. Есть синтетический demo mode, поэтому репозиторий и скриншоты не содержат Registry конкретного компьютера.

Главная идея следующего этапа:

**Снимок A → установка/изменение → Снимок B → показать, что именно изменилось.**

Diff должен показывать:

- добавленные / удалённые / изменённые ключи;
- добавленные / удалённые / изменённые значения;
- данные «до / после»;
- фильтры по hive/path/типу изменения;
- экспортируемый диагностический отчёт.

Я специально не позиционирую проект как инструмент автоматического изменения Registry. Интереснее задача **объяснимости**: быстро понять, что реально сделал installer, policy, driver или изменение конфигурации.

В прототипе есть EN/RU интерфейс, четыре demo-скриншота и публичный roadmap.

**GitHub:** https://github.com/musikfed/registry-change-explorer
